# Sevana Development Roadmap

**Project:** Sevana - Animal Rescue Platform  
**Version:** 1.0  
**Development Phase:** MVP Sprint  
**Timeline:** 4 Days

---

# Purpose

This roadmap defines the development plan for Sevana.

It provides:

- Development phases
- Sprint goals
- Feature priorities
- Team responsibilities
- Milestones
- Future roadmap

This document should be updated whenever a phase is completed.

---

# Vision

Build a secure, scalable, modern animal rescue platform that connects:

- Citizens
- Volunteers
- NGOs
- Veterinarians
- Administrators

through a single ecosystem.

---

# MVP Goal

By the end of this sprint, Sevana should allow a user to:

✅ Register

✅ Login

✅ View Profile

✅ Report an Animal

✅ Upload Images

✅ View Nearby Reports

✅ Accept Rescue Requests

✅ Update Rescue Status

✅ Earn XP

✅ View Leaderboard

✅ View Nearby NGOs

✅ View Nearby Vets

✅ Receive Notifications

The application should be fully functional from frontend to backend.
